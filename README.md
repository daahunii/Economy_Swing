# Economy Swing

경제·정책·시장 데이터를 과거 사례와 비교하고, 관심을 가질 만한 한국·미국 섹터와 기업을 근거와 함께 탐색하는 투자 리서치 웹 프로그램.

> 현재 단계: **공식 경제지표 실제 연동**. 기본 모드는 `live`이며 금리·환율·현물 원자재·VIX 등 10개 실제 지표를 FRED에서 수집합니다. 토스증권 시세 어댑터는 구현했으며 사용자 액세스 토큰 설정이 필요합니다. DB·AI·정기 수집과 투자 모델 검증은 미완료입니다.

## 현재 사용할 수 있는 기능

- 대시보드: 주요 지표 카드, 시장 차트, 국가 선택, 섹터 순위.
- 경제 지표: 공식 지표 10개의 시계열·변화·원 출처·관측/수집/갱신 시각·지연 상태.
- 섹터: 실제 모드는 미국 10개·한국 4개 ETF 대용 지표부터 시작. 토스 토큰 설정 전에는 연결 대기. 실제 기회 점수는 모델 검증 전까지 보류.
- 과거 관계: 실제 시계열이 연결된 경우 공통 관측일 기반 5/20/60관측치 탐색. 당시 발표 시점의 전략 백테스트와 구분.
- 학습: 용어 8개, 검색·분류, 초보자 설명 모드 저장.
- 공통: 통합 검색, 데이터/모델 안내, 오류·로딩 화면, 모바일 레이아웃. 본문 16px 및 확대된 표·설명·차트 글자.

## 로컬 실행

Node.js 22 LTS 및 Python 3.12 이상이 필요합니다. 작업 디렉터리는 `eco_swing/`입니다.

```bash
npm ci
python3 -m venv apps/backend/.venv
apps/backend/.venv/bin/python -m pip install -r apps/backend/requirements-dev.txt
npm run dev
```

- 화면: `http://127.0.0.1:3100`
- API 문서: `http://127.0.0.1:8100/docs`
- 한 명령이 웹/API를 함께 실행하며 `Ctrl+C`로 함께 종료합니다. 포트 충돌 시 `PORT`와 `API_PORT` 환경변수를 변경합니다.
- macOS에서 `python3`가 오래된 시스템 Python을 가리키면 Python 3.12 이상 인터프리터의 절대 경로를 사용합니다.
- 기본 모드는 공식 공개 지표를 요청하므로 외부 네트워크가 필요합니다. 시세 토큰이 없어도 공식 거시 지표는 조회됩니다.
- 오프라인 합성 모드는 루트 `.env.local`에 `ECONOMY_DATA_MODE=demo`를 명시합니다. 수집 오류 시 자동으로 전환되지 않습니다.
- [실제 데이터 및 토스증권 설정](docs/runbooks/live-data.md)의 발급 명령과 Vercel 환경변수 절차를 참고하세요. 비밀 값은 채팅이나 GitHub에 공유하지 않습니다.

## 개발 검증

```bash
npm run typecheck
npm run build
cd apps/backend
.venv/bin/python -m pytest
```

OpenAPI 변경 후 루트에서 `npm run contracts`를 실행하면 Python 스키마에서 TypeScript 계약을 생성합니다. 생성된 `schema.d.ts`를 직접 수정하지 않습니다.

합성 자료 재생성은 루트에서 `python3 scripts/generate_demo.py`를 사용합니다. 점수 설정을 바꾼 경우 함께 재생성하고 모델 버전을 갱신합니다.

빌드/개발은 현재 환경에서 확인한 Webpack을 사용합니다. Turbopack은 로컬 실행 환경의 내부 포트 제한으로 실패하여 전환했습니다.

## 핵심 흐름

```text
경제 변화 파악
  → 과거 유사 조건 검증
  → 현재 영향을 받는 섹터 탐색
  → 기업의 실적·가격·위험 비교
  → 판단 근거와 무효화 조건 기록
  → 이후 실제 성과 확인
```

프로그램은 매매 주문을 실행하지 않습니다. 분석 결과는 매수 지시가 아닌 리서치 후보로 다룹니다.

## 설계 방향

- **처음에는 작게:** 거시경제·섹터·과거 관계를 먼저 연결하고, 뉴스·기업·성과 분석을 순차적으로 추가합니다.
- **유지보수 가능한 분리:** 화면은 Next.js, 수집·계산·저장은 Python/FastAPI가 담당합니다. AI는 검증된 숫자를 설명합니다.
- **추적 가능한 결과:** 데이터 출처, 관측·발표·수집 시각, 계산 버전, 분석 기준일을 결과와 함께 보존합니다.
- **쉽게 읽는 분석:** 숫자 → 의미 → 비교 → 주의점 → 다음 확인 항목 순서로 설명합니다.
- **불완전함을 드러내기:** 데이터 부족·오래된 자료·미연동 상태를 점수나 가짜 실시간 값으로 감추지 않습니다.

## 프로젝트 운영

- 작업 위치: `eco_swing/`
- 제품 이름: **Economy Swing**. 원본 기획의 `Market Radar`는 참고 문서상의 이전 명칭입니다.
- 배포 목표: **Vercel**. Next.js 웹과 FastAPI API를 배포하고, 영구 데이터는 외부 관리형 PostgreSQL에 저장합니다. 장시간 작업은 API 요청과 분리합니다.
- 설계 기준일: 2026-10-15, 사용자 시간대 `Asia/Seoul`
- 설계 근거: 사용자가 제공한 Market Radar 전체 기획 1~50항 및 쉬운 기업·재무 분석 기획 51~77항
- 실행 명령은 위 로컬 실행 및 개발 검증 절차를 사용합니다.

설계를 변경할 때는 관련 문서와 결정 기록을 같은 변경에 포함합니다. 코드와 문서가 다른 경우 차이를 숨기지 않고 수정합니다.
