# 실제 데이터 연결 및 토스증권 설정

기준일: 2026-10-15. 코드의 기본 모드는 `live`입니다. `demo`를 명시적으로 선택한 경우만 합성 fixture를 사용합니다. 실제 수집 실패 시 데모 데이터로 대체하지 않습니다.

- 원본은 `https://fred.stlouisfed.org/data/{ID}` 공개 표입니다. 공식 원본 링크·관측일·공급자 갱신·수집 시각을 반환합니다.
- 공개 표의 처음 보이는 행과 `extra-rows` 지연 렌더링 행을 모두 읽습니다. JavaScript는 실행하지 않습니다.
- 시계열 ID·일별 빈도·날짜·유한 숫자·중복 충돌을 검증합니다. 형식 변경 시 자료 없음으로 표시합니다.
- 현재 확인한 graph CSV 경로는 실패하여 사용하지 않습니다. 공개 HTML 경로가 변경되면 어댑터를 수정해야 합니다.
- 최근 유효 관측치 최대 1,300개를 사용하며 결측·휴일·미래 날짜를 채우지 않습니다.
- 광의 달러 지수는 DXY가 아닙니다. WTI/브렌트 현물은 선물 시세가 아닙니다.
- 1/5/20 변화는 유효 관측치 기준입니다. 월간 지표를 일별처럼 처리하지 않습니다.
- 관측 후 7일을 넘거나 갱신 요청에 실패한 마지막 성공 자료는 `stale`로 표시합니다. 이는 보수적인 표시 규칙이며 시장 실시간성의 보장이 아닙니다.
- 수집은 요청 시 수행하고 인스턴스 안에서 30분 캐시합니다. 대시보드 스냅샷은 3분, 실패는 1분 캐시합니다. 인스턴스 재시작 시 사라지는 캐시로 영구 저장이나 예약 수집을 대체하지 않습니다.

출처 정책: [FRED 이용 조건](https://fred.stlouisfed.org/legal/terms/), [VIX 원본 및 인용 조건](https://fred.stlouisfed.org/series/VIXCLS). S&P 500·Nasdaq의 사전 승인 필요 자료를 FRED에서 무단 대용하지 않습니다.

## 2. 토스증권 시세 연결

공식 규격: [Open API 안내](https://p.tossinvest.com/ko/open-api), [개발 문서](https://developers.tossinvest.com/), [실제 OpenAPI JSON](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json).

현재 서버는 다음 **읽기 전용 경로만** 사용합니다.

- `GET /api/v1/candles`: ETF 수정주가 일봉.
- `GET /api/v1/market-indicators/{symbol}/candles`: KOSPI 일봉.
- 서버는 계좌·잔고·주문·취소 API를 사용하지 않습니다.

### A. 토큰 발급 전인 경우

1. 토스증권 웹에서 `설정 → Open API`로 이동해 Client ID와 Client Secret을 발급합니다. 필요한 허용 IP도 공식 안내에 맞게 설정합니다.
2. 로컬 프로젝트 루트에서 아래 명령을 실행합니다.

```bash
apps/backend/.venv/bin/python scripts/setup_toss_token.py
```

3. `yes` 입력 후 Client ID/Secret을 숨김 입력합니다. 스크립트는 공식 `POST /oauth2/token`에 `client_credentials` form 요청을 전송합니다.
4. 발급된 토큰은 Git에서 제외된 루트 `.env.local`에만 저장됩니다. Client ID/Secret은 저장하지 않으며 토큰을 콘솔에 출력하지 않습니다.

**토큰 재발급은 기존 토큰을 무효화할 수 있습니다.** 이미 같은 API 계정을 다른 프로그램에서 사용한다면 갱신 시점을 함께 관리해야 합니다. 토큰/Secret을 채팅·GitHub·스크린샷에 공유하지 않습니다.

이 스크립트는 사용자가 직접 실행하는 설정 도구이며 이번 개발 과정에서 실제 계정으로 실행하지 않았습니다.

### B. Vercel 설정

1. 백엔드 Vercel 프로젝트 → Settings → Environment Variables.
2. `TOSS_ACCESS_TOKEN`에 `.env.local`의 같은 이름 오른쪽 값만 복사합니다. Client ID나 Secret을 대신 넣지 않습니다.
3. `ECONOMY_DATA_MODE=live` 설정 또는 기본값 사용.
4. 필요한 Production/Preview 환경을 선택하고 **백엔드를 재배포**합니다.
5. 프런트의 `BACKEND_URL`은 기존 백엔드 HTTPS origin을 유지합니다. 토스 토큰은 프런트에 설정하지 않습니다.
6. 화면의 데이터 안내에서 연결된 섹터 수와 오류 상태를 확인합니다.

토스의 허용 IP 기능을 사용하는 경우 실제 호출 환경의 외부 IP가 허용되어야 합니다. Vercel의 외부 IP가 고정이라고 가정하지 않습니다. 필요 시 고정 egress/개인 서버 구성을 검토하며 허용 IP 검사를 우회하지 않습니다.

토큰은 발급 응답의 `expires_in`에 따라 만료됩니다. 만료·접근 거부·요청 제한은 연결 상태에 표시합니다. 재발급 후 환경변수를 변경했다면 백엔드를 다시 배포해야 합니다.

### C. 로컬 설정

`npm run dev`가 루트 `.env.local`을 읽어 Python에 전달합니다. 설정 후 기존 개발 서버를 종료하고 다시 실행합니다. 웹의 같은 origin 요청은 Next.js를 통해 Python으로 전달됩니다.

### D. 토큰 갱신 구조의 한계

토스는 Client당 유효 토큰을 하나만 유지하므로 Vercel 인스턴스가 시작될 때마다 자동 발급하면 다른 인스턴스의 토큰을 무효화할 수 있습니다. 현재는 명시적으로 발급한 서버 토큰만 사용합니다. 무인 운영에는 공유된 영구 토큰 저장소·갱신 잠금·만료 작업이 추가로 필요합니다.

## 3. 실제 섹터 범위와 분석 제한

- 미국: XBI, SMH, GRID, XLK, XLV, XLF, XLE, XLU, XLRE, XLI.
- 한국: KODEX 반도체 091160, 자동차 091180, 은행 091170, 철강 117680부터 연결.
- 초기 20개 데모 섹터를 근거 없이 실제 시세로 바꾸지 않습니다. 실제 연결 목록은 검토한 대용 ETF 14개이며 추가 목록은 별도 검증합니다.
- GRID는 글로벌 편입 ETF이며 미국에 상장되어 있어 `US`로 분류합니다. 미국 기업만의 전력 섹터로 해석하지 않습니다.
- 미국 벤치마크는 SPY ETF 대용입니다. S&P 500 지수 자체가 아닙니다. 한국은 KOSPI 가격지수를 사용합니다.
- 일봉 요청은 최대 2페이지/400개 봉으로 제한하며 공식 `nextBefore` 커서를 그대로 전달하고 중복 봉을 제거합니다.
- 시장 현지 날짜가 진행 중인 당일 봉은 보수적으로 제외합니다. 현재가나 오늘 장중 움직임을 표시하는 기능이 아닙니다.
- 실제 토스 인증 자료가 없으면 ETF와 지수 값은 `null`/연결 대기로 표시합니다. 0% 수익률로 채우지 않습니다.
- 시장 대비 최근 수익률은 섹터와 벤치마크의 **동일 시작일·종료일** 값이 있을 때만 계산합니다.
- 이벤트 스터디는 변수·섹터·벤치마크의 정확히 일치하는 공통 날짜만 사용합니다. 최대 낙폭은 해당 구간의 원래 섹터 가격 경로 전체로 계산합니다.
- 최신 수정 자료 기반 관측 관계이며 발표 시각·가용 시각을 재현한 투자 전략 백테스트가 아닙니다. 비용·세금·환전·배당 재투자 총수익을 보장하지 않습니다.
- **데모 모델의 점수를 실제 자료에 적용하지 않습니다.** 모델 검증 전 기회 점수·요소 점수는 보류합니다.

## 4. 검증 기록

- 공식 경제지표 10개 실제 조회 성공, 날짜·공급자 상태 확인.
- 토스: 공식 스펙 확인 및 고정 응답 테스트. 사용자 토큰 미발급 상태이므로 실제 인증 호출은 미검증.
- Python 테스트 25개: 기존 계산·API, FRED 지연 행/결측/형식/시각, 토스 페이지·중복·당일 제외, 실제 모드에서 데모 혼합 방지, 실패 시 명시적 빈 값, 마지막 성공값 지연 표시.
- TypeScript와 프로덕션 빌드 통과. 브라우저에서 실제 지표 및 데스크톱/모바일 가독성을 확인.
