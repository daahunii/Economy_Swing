# 01. 제품과 전체 기능

상태: 설계안 · 기준일: 2026-10-15

## 1. 제품 목표

Economy Swing은 한국·미국 시장을 대상으로 다음 질문에 답하는 리서치 플랫폼입니다.

1. 지금 경제와 시장에서 무엇이 달라졌는가?
2. 그 변화는 왜 중요하며 어떤 경로로 기업에 영향을 주는가?
3. 과거 비슷한 조건에서 산업과 시장은 어떻게 움직였는가?
4. 현재 주목할 만한 섹터는 무엇이며 근거는 충분한가?
5. 그 섹터에서 어떤 기업을 비교해볼 만한가?
6. 기업의 재무 상태와 현재 가격은 어떤 의미인가?
7. 어떤 조건에서 지금의 판단을 다시 검토해야 하는가?
8. 이전 분석은 시장 대비 어느 정도의 성과를 보였는가?

실시간 주문, 자동매매, 수익 보장, 검증되지 않은 AI 주가 예측은 초기 제품 범위에 포함하지 않습니다.

## 2. 제품 원칙

| 원칙 | 화면과 기능에 적용하는 방법 |
| --- | --- |
| Macro → Sector → Stock | 기업 후보에서 상위 섹터와 연결 경제 변수를 역으로 확인할 수 있음 |
| 과거 검증 후 현재 탐색 | 관계 분석 결과와 현재 조건의 유사점·차이점을 함께 표시 |
| 정량 계산과 해석 분리 | 계산은 Python, AI는 전달받은 결과 설명 |
| 근거와 위험을 함께 제공 | 긍정 요인·반대 근거·판단 무효화 조건을 나란히 제공 |
| 절대 성과와 초과 성과 구분 | 종목/섹터 수익률과 해당 시장 벤치마크 차이를 분리 |
| 상관관계와 인과관계 구분 | 통계적 관찰과 경제적 설명 가설을 별도 항목으로 표시 |
| 확률과 불확실성 전달 | 표본 수·관측 기간·편차·데이터 품질을 함께 제공 |
| 시장의 선반영 고려 | 이벤트 발생 사실과 시장 기대 변화의 차이를 구분 |
| 결과 추적 | 당시 근거와 버전을 보존해 사후 성과와 비교 |
| 쉬운 설명 | 현재 값·추세·동종 비교·예외를 연결해 설명 |

기회 점수는 상대적인 리서치 우선순위입니다. `84점 = 상승 확률 84%`처럼 해석하지 않습니다. 역사적 승률 역시 미래 상승 확률로 제시하지 않습니다.

## 3. 대표 사용자 흐름

### 3.1 오늘의 시장을 이해하기

대시보드 → 한국/미국 시장 선택 → 지표 변화 확인 → 영향을 받는 섹터 → 관련 과거 관계 확인.

### 3.2 특정 경제 변화의 영향을 확인하기

경제 지표 → 지표의 의미와 변화 → 연결된 섹터 → 과거 분석 조건·표본 → 현재 상황과 차이 확인.

### 3.3 기업을 공부하고 후보로 저장하기

섹터 → 기업 후보 → 재무 건강검진 → 동종 기업 비교 → 투자 논리와 위험 → 관심 목록 저장.

### 3.4 지난 판단을 검증하기

저장된 후보 → 당시 분석 원본 → 경과 기간별 성과 → 벤치마크 비교 → 판단 변경과 실패 원인 기록.

추가 메뉴가 완성되기 전에는 동작하는 것처럼 보이는 빈 화면을 제공하지 않습니다. 필요한 경우 개발 예정으로 명시합니다.

## 5. Dashboard

- 국가 선택: 전체 / 한국 / 미국.
- 조회 기준 시각, 시장별 최신 거래일, 데이터 지연 여부 표시.
- 한국·미국 시장 상태: Risk-On / Neutral / Risk-Off / 판정 보류.
- 미국 국채금리, 환율, 원자재, 변동성, 주요 지수의 현재 값과 변화.
- 변화량은 비교 구간과 단위를 명시: 거래일, 관측치, %, %p, bp 등.
- 섹터 상위 후보와 점수, 전일 순위 변화, 주된 이유, 신뢰도.
- 현재 변화 → 경제적 전달 경로 → 섹터 → 과거 근거의 연결 카드.
- 연동 후에는 주요 경제·정책 이벤트와 시장 요약 제공.
- 기업 분석 도입 후에는 시장별 기업 후보와 최근 저장 항목 표시.
- 데이터가 부족하면 순위에서 제외된 항목 수와 이유도 확인 가능.

### 6.2 상세 화면

- 현재 값, 단위, 관측일, 발표일, 수집 시각, 출처 링크.
- 1D / 5D / 20D 등 변화. 월·분기 지표는 발표 주기에 맞게 별도 표시.
- 기간별 시계열 차트와 경제 이벤트 표시.
- 관련 섹터 및 예상 전달 경로. 방향은 단정 대신 조건과 반대 요인 포함.
- 경제 원리와 용어 설명, 연결된 과거 관계 분석.
- 데이터가 수정되었는지와 최신값/당시 발표값 구분.

## 7. Sectors

### 7.1 섹터 구성

- 미국: 기술, 헬스케어, 바이오, 금융, 에너지, 유틸리티, REIT, 산업재, 방산, 반도체 등 약 10개부터 시작.
- 한국: 반도체, 자동차, 바이오/제약, 방산, 조선, 원전, 전력기기, 2차전지, 화학, 금융 등 약 10개부터 시작.
- 섹터와 테마를 구분하고, 반도체·기술처럼 겹치는 분류는 관계를 명시.
- ETF/지수를 대용 지표로 쓰는 경우 추적 대상, 통화, 한계와 유효 기간 표시.
- 최종 초기 목록은 데이터 공급 및 과거 분석 가능 기간을 확인한 뒤 확정.

### 7.2 목록과 상세

- 국가, 점수, 신뢰도, 데이터 상태 필터와 정렬.
- 종합 점수와 Macro / Historical / News / Momentum / Valuation 분해.
- 현재 모델에 포함되지 않은 요소는 `미적용`, 필수 데이터 결측은 `산출 불가`로 구분.
- 연결 경제 변수, 이벤트, 긍정·부정 근거, 섹터 특유 위험.
- 과거 관계의 평균·중앙값 수익률, 초과 수익률, 승률, 표본 수와 분산.
- 기업 분석 도입 후 관련 기업으로 이동.

## 8. Stocks

- 종목 검색, 국가·거래소·섹터 필터, 관심 목록.
- 동일 기업의 복수 상장·티커 변경·상장폐지 이력을 구분.
- 기업 개요, 사업 구조, 섹터 연결, 가격 기준일.
- Sector / Fundamental / Momentum / Valuation / News / Risk 점수 분해.
- 매출·영업이익·순이익·EPS·ROE·부채·FCF·영업이익률 분석.
- PER·Forward PER·PBR·PSR·EV/EBITDA와 업종·과거 범위 비교.
- 1주·1개월·3개월 수익률, 상대 강도, 거래량, 이동평균, 52주 고점과 거리.
- 공시·실적·뉴스 연결, 재무 건강검진, 3~5년 추세와 동종 기업 비교.
- 기회 요인, 반대 근거, 위험 요인, 판단을 다시 검토할 조건.
- 과거 후보 편입 당시의 원본과 경과 성과.

금융업처럼 일반 제조업 지표가 부적절한 업종에는 별도 지표 정책을 적용하거나 해석 제한을 표시합니다.

## 9. 쉬운 기업·재무 분석

### 9.1 초보자 모드

- 계정 또는 브라우저 설정으로 ON/OFF 상태 저장.
- ON: 한글 지표명, 한 줄 설명, 비교, 주의점, 다음 확인 항목 우선.
- OFF: 원래 지표명, 수치, 계산 기준, 과거 분위수 등 밀도 높은 정보 우선.
- 두 모드의 원본 데이터와 계산 결과는 동일하며 표시 방식만 달라짐.
- 용어 도움말은 클릭·키보드·터치로 열 수 있고, 마우스 올리기에만 의존하지 않음.

### 9.2 재무 지표 카드의 공통 구조

1. 지표 이름, 값, 단위, 결산 기간, 공시 기준일.
2. 한 줄 의미와 쉬운 예시.
3. 계산 방법과 사용한 데이터의 범위.
4. 높거나 낮을 때 가능한 해석.
5. 같은 산업 및 기업 과거 값과의 비교.
6. 해석이 달라지는 예외와 함께 볼 지표.
7. 해당 기업의 현재 상태와 왜 중요한지.
8. 자세히 알아보기 링크.

### 9.3 설명 대상과 주의점

| 대상 | 핵심 설명 | 반드시 포함할 주의점 |
| --- | --- | --- |
| PER | 이익 대비 주가 수준 | 적자·일회성 이익, 향후 실적 악화, 업종 차이 |
| Forward PER | 예상 이익 기준 가격 | 전망치 출처·기준일·예측 오차 |
| PBR | 순자산 대비 시장가치 | 무형자산, 음의 자본, 업종 차이 |
| EPS | 주식 한 주당 이익 | 기본/희석, 주식 수 변경, 분할 조정 |
| ROE | 자기자본 대비 이익 | 부채·자사주·작은 자본으로 인한 왜곡 |
| 매출 | 사업 규모와 성장 | 환율·인수 효과, 매출만 늘고 이익이 줄 수 있음 |
| 영업이익·순이익 | 본업과 최종 손익 | 일회성·금융·세금 효과를 구분 |
| 영업이익률 | 판매액 대비 본업 이익 | 동종 업종과 기간을 맞춰 비교 |
| 부채비율 | 자본 대비 부채 | 산업별 기준, 음의 자본, 금융업 적용성 |
| FCF | 운영·설비 투자 후 현금 | 정의, 투자 시점, 업종 특성을 함께 표시 |

PSR, EV/EBITDA, ROA, 배당수익률, 시가총액 등도 같은 설명 체계로 확장합니다.

### 9.4 재무 이야기와 건강검진

- 3~5년 매출·이익·EPS·ROE·FCF 추세를 함께 설명.
- 매출 성장보다 영업이익이 더 빠른지, 현금이 이익을 뒷받침하는지 확인.
- 성장·수익성·현금흐름·부채·가격 수준을 항목별 평가.
- `좋음/보통/주의/자료 부족` 판정마다 업종별 규칙과 근거 제공.
- 낮은 PER, 높은 ROE, 높은 배당률을 단독으로 좋은 투자라고 판정하지 않음.
- AI 설명 전에는 동일한 구조의 규칙 기반 설명으로 시작 가능.

## 10. Intelligence

- 뉴스 목록보다 `무슨 이벤트이며 무엇에 영향을 주는가`를 우선 제공.
- Macro / Industry / Company / Policy / Geopolitics / Earnings / M&A / Clinical Trial / Regulation / Supply Chain 분류.
- 국가, 발생 시각, 발표 시각, 기업·섹터, 방향, 영향 경로, 불확실성 구조화.
- 확정된 사실·예상·소문·분석 의견을 분리.
- 동일 기사·재송고·동일 이벤트 묶음 처리.
- 원문 링크, 요약, 출처 신뢰도, AI 추출 신뢰도를 구분.
- 유사 과거 이벤트와 차이, 반대 뉴스 및 이미 반영되었을 가능성 제공.
- 데이터 공급 실패 또는 AI 분석 실패 시 해당 상태를 표시.

## 11. Backtest / Relationships

### 11.1 MVP 1: 검증된 관계 조회

- 미리 정의된 변수·조건·섹터·기간 조합의 결과 조회.
- 분석 기간, 이벤트 정의, 대용 지표, 벤치마크, 표본을 확인.
- 이벤트별 상세와 분포 확인. 유리한 평균 하나만 보여주지 않음.
- 현재 상황이 과거 조건을 충족하는지와 충족하지 않는 점 확인.

### 11.2 MVP 4: 사용자 분석 실행

- 변수, 상승/하락, 변화 기준, 임계값, 기간, 국가, 섹터 선택.
- T+1 / 5 / 20 / 60 / 120 거래일 결과.
- 절대·초과 수익률, 승률, 표본 수, 변동성, 최대 낙폭.
- 샤프 비율 등 전략 성과는 명시적인 포트폴리오 시뮬레이션이 있는 경우에 제공.
- 비용·체결 가정, 이벤트 중첩, 데이터 시점 제약 확인.
- 작업 상태와 실패 이유 제공, 같은 조건의 결과 재사용.
- 결과를 관심 관계로 저장하고 조건·모델 버전을 보존.

## 12. 후보 기록과 Performance

- 편입 일시, 종목·섹터, 점수, 근거, 위험, 기준 가격, 벤치마크를 원본으로 저장.
- 논리 변경과 제외는 별도 기록. 과거 판단을 최신 설명으로 덮어쓰지 않음.
- 1 / 5 / 20 / 60 거래일 성과 추적. 필요 시 120일 확장.
- 미도달·결측·거래정지·상장폐지 상태를 구분.
- 시장별 적중률·평균·중앙값·초과 수익률·표본 수·분석 기간 표시.
- 절대 상승 적중률과 시장 초과 적중률 구분.
- 집계 창별 성과, 섹터별 편향, 실패 사례, 버전별 차이 확인.
- 후보 성과와 실제 사용자 보유 계좌 성과를 구분.

## 13. Learn

- 금리, 채권금리와 할인율, 환율, 원자재, 물가, 경기순환, 섹터 로테이션.
- 실적·가치평가·수익성·안정성·현금흐름·배당·주식시장 용어 사전.
- 용어 상세: 정의 → 계산 → 예시 → 해석 → 예외 → 비교 → 퀴즈.
- 지표 카드·차트·위험 설명에서 해당 개념으로 바로 이동.
- 경제적 전달 경로는 조건부 설명으로 제공하며 필연적 주가 방향처럼 표현하지 않음.

## 14. 공통 사용자 경험

- 모바일에서는 시장 선택 → 요약 → 상세로 이동하며 큰 표는 가로 스크롤 또는 카드로 전환.
- 필터와 분석 조건은 URL에 반영하여 새로고침·뒤로 가기·링크 공유 지원.
- 값이 없는 상태, 불러오는 상태, 오류, 오래된 데이터, 기능 미연동을 구분.
- 상승/하락을 색상뿐 아니라 부호·텍스트·아이콘으로 전달.
- 차트에는 단위·축·범례·기간과 접근 가능한 수치 요약 제공.
- 시각은 사용자 시간대와 시장 기준을 명시. 한국·미국의 서로 다른 거래일을 숨기지 않음.
- 관심 목록은 삭제·복구 또는 확인 가능한 되돌리기를 지원하도록 설계.
- 서비스 설정과 데이터 연결 상태는 운영 설정에서 확인하며 비밀키는 화면에 노출하지 않음.
