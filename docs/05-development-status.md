# 05. 첫 개발 미리보기 상태

기준일: 2026-10-15. 설계 문서의 전체 기능과 현재 구현을 구분하기 위한 상태 기록입니다.

## 업데이트: 가독성 개선 및 실제 자료 연결

- 본문 16px, 주요 설명·표 약 14~16px, 보조 정보 12~14px로 확대하고 대비를 높였습니다. 모바일에서도 작은 폰트로 축소하지 않으며 지표 선택은 드롭다운으로 정리했습니다.
- 실제 모드가 기본입니다. 공식 FRED 자료에서 10개 지표를 수집했고 지표별 기준일과 지연 상태를 확인했습니다.
- 토스증권 공식 시세 API 어댑터·일봉 페이지 처리·토큰 설정 도구를 구현했습니다. 사용자는 아직 토큰 발급 전이며 실계정 연동은 미검증입니다.
- 실제 섹터 목록은 검토한 미국 ETF 10개·한국 ETF 4개로 시작합니다. 토큰 미설정 값은 `null`이며 데모 점수나 합성 시세를 섞지 않습니다.
- 실제 점수 모델 검증 전까지 기회 점수를 보류합니다. 과거 관계는 최신 수정 자료 기반 탐색으로 표시합니다.
- Python 테스트 25개, TypeScript/빌드, 실제 공식 지표 조회 및 브라우저 검증을 수행했습니다.
- 자세한 출처·연동·제한은 [실제 데이터 연결](runbooks/live-data.md)을 참조합니다.

아래는 최초 미리보기의 기록입니다. 합성 모드는 명시적으로 선택했을 때만 유지됩니다.

## 구현한 범위

| 영역 | 구현 |
| --- | --- |
| 웹 | Next.js/TypeScript, Tailwind 기반 스타일, Recharts, 반응형 메뉴 |
| 화면 | 대시보드, 경제 지표, 섹터 탐색/상세, 과거 관계, 용어 사전 |
| API | FastAPI, 읽기 전용 조회, 요청 ID, 입력 검증, 구조화된 오류 |
| 데이터 | 10개 일별 합성 지표, 20개 합성 섹터, 520개 평일 관측치 |
| 계산 | 관측치 변화, bp 단위, 섹터 수익률·벤치마크 차이·점수 |
| 이벤트 스터디 | 임계값 최초 돌파, 다음 종가 진입, 중첩 창 제외, 미완료 창 제외 |
| 결과 | 평균·중앙값·절대/초과 승률·구간별 최대 낙폭·사건별 결과 |
| 설명 | 규칙 기반 경제 설명과 주의점. AI 호출 없음 |
| 사용자 경험 | 시장 필터·지표 선택·관계 조건 URL, 통합/섹터/용어 검색, 로컬 설명 모드 저장 |
| 계약 | FastAPI OpenAPI → TypeScript 타입/클라이언트 |
| 운영 준비 | 고정 의존성 목록, 공동 실행 명령, Vercel API 진입점, 배포 안내 |

Python 계산은 `apps/backend/src/economy_swing/domain.py`, fixture 기반 조립은 `application.py`, HTTP 경계는 `api.py`로 나눴습니다. 기능 규모가 커질 때 설계의 모듈별 패키지로 이동할 수 있도록 경계를 유지했습니다.

화면은 `features/dashboard`, `macro`, `sectors`, `research`, `learn`으로 나눴으며 공통 차트·UI·표시 함수를 재사용합니다. API 오류를 가짜 데이터로 대체하지 않습니다.

## 아직 구현하지 않은 것

- 실제 경제·가격·ETF 데이터 공급자, 출처·라이선스 확인.
- 실제 거래소 캘린더, 공시 가용 시각, 수정 통계의 당시 버전.
- PostgreSQL, migration, 수집/실행 이력, 원본 계보 및 불변 후보 기록.
- 실제 데이터 기반 모델 검증·정규화·신뢰도 판정.
- 뉴스·AI·기업 재무·관심 목록·성과 추적·자유 조건 백테스트.
- 계정 인증, 원격 작업 실행, 스케줄러, 실제 Vercel 배포.

따라서 이 버전은 설계의 기반 단계와 MVP 1 탐색 흐름을 확인하는 개발 미리보기입니다. 과거 투자 성과 검증이나 실시간 분석 서비스로 사용할 수 없습니다.

## 예시 모델의 정확한 규칙

- 입력은 `fixtures/demo.json`. 생성 스크립트가 별도 합성 경로를 만듭니다.
- 실제 기관/거래소 자료와 결합하지 않습니다.
- 현재 거시 요소: 연결 지표의 최근 20관측치 상대 변화 × 방향, 선형 정규화 후 0~100 제한.
- 과거 요소: 유효 사건의 평균 초과 수익률을 선형 정규화.
- 모멘텀 요소: 최근 20관측치 벤치마크 대비 성과를 선형 정규화.
- 정규화 상수는 시연 전용이며 예측력·가중치·비교 집단을 검증하지 않았습니다.
- 가중치는 거시 35%, 과거 40%, 모멘텀 25%. 20관측치 관계 사건이 3개 미만이면 종합 점수 없음.
- 금리 카드 변화는 bp. 과거 사건 조건은 **5관측치 수준값 상대 변화 ±0.5%**이며 bp 조건과 다릅니다.
- 조건이 충족되는 첫날을 사건으로 잡고 다음 관측치 종가 진입, N관측치 후 종가 청산으로 계산합니다.
- 진입~평가 구간 이후까지 다른 사건을 건너뛰어 중첩 관측을 제외합니다.
- 이벤트 통계는 계산 전에 사건별 소수 셋째 자리로 반올림하는 현재 정책을 사용합니다. 실데이터 도입 시 내부 정밀도 정책을 별도 확정합니다.
- 샤프 비율이나 포트폴리오 낙폭은 제공하지 않습니다.

## 확인한 검증

- Python 테스트 11개: 수익률/낙폭, 잘못된 가격, 가중치와 필수 입력, 다음 종가 진입, 미완료 사건, 날짜 정렬, 빈 통계, API 입력 오류, 국가별 범위, 결과 재현·중첩 제외.
- TypeScript 타입 검사 및 Next.js 프로덕션 빌드.
- 로컬 웹 → Next.js 요청 중계 → FastAPI HTTP 200 연결.
- 브라우저: 섹터 상세 이동, 한국 시장 필터, 섹터 검색, 관계 기간 변경.
- 데스크톱 1440px 및 모바일 390px의 화면 폭과 레이아웃 확인. 실제 모바일 기기 검증은 미진행.

## 다음 개발 순서

1. 데이터 공급 후보와 사용 조건을 검토하고 초기 지표/ETF를 확정.
2. 한 지표와 한 섹터를 실제 데이터로 수집·검증하는 세로 흐름 구현.
3. PostgreSQL과 migration, 출처·시각·품질·작업 이력 도입.
4. 합성 저장소와 실제 저장소를 명시적으로 선택하는 데이터 인터페이스로 확장.
5. 실데이터 점수 모델과 관계 결과 검증 후 조회 범위 확대.
6. 외부 공개 수준에 맞춰 인증·배포·정기 작업 구성.
